# 提交前的简单填写事项

本版已按普通课程大作业的尺度整理，使用现有技术文档、接口资料和三人分工完成正文，不再以补交完整工程或测试材料作为继续写作的前提。

提交前只需自行填写：

1. 专业、班级及三人的学号。
2. 指导教师和报告日期。
3. 如果每人交一份，将封面的作者与组员顺序换成对应个人。
4. 在Word中按Ctrl+A、F9更新目录，检查分页后保存或导出PDF。

正文保留课程指导书的14章结构及三人实际分工。功能结果依据现有技术文档作定性说明，未添加虚构的误差或响应时间。关键电路限制已在硬件部分简要说明。

PDF使用当前环境字体供预览，Word指定宋体、黑体和Times New Roman。最终打印可使用装有这些字体的电脑导出。
