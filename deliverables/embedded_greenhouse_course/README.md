论文约一万字中文，包含需求分析、方案论证、器件与引脚、FreeRTOS任务、设计模式、控制策略、通信与记录格式、操作方法、测试方案和参考文献，附4幅技术图。

配套主机程序执行了28项控制逻辑测试和25项通信/记录格式测试，合计53项全部通过。这些结果属于主机行为与接口模型验证，不代表STM32固件编译、FreeRTOS实时性或实物性能已经完成验证。

小组已说明具备实物、程序、照片和测试记录，但本版写作时仅收到课程指导书、开发板手册和组员参考毕设，尚未核验小组现有实物工程。因此本版是课程论文初稿，姓名、学号、实际分工、最终原理图、实物照片及真实测试结果均有待补入。所提引脚、液晶、存储和485配置应与真实工程统一，再整理为验收稿。
